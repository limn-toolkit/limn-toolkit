# Every two- and three-letter code ICU reads as another language, and the tag it reads it as,
# then every numeric region ICU reads as a two-letter one, then every retired two-letter region it
# reads as a current one: the alias and region rows of
# limn-toolkit/src/test/resources/limn/i18n/cldr-locale-facts.txt, which
# scripts/i18n/dump-cldr-locale-facts.mjs asks ICU for, copied line for line.
# LanguageAliasesTest holds the two files to the same rows in the same order.
#
# alias <code> <replacement>   the replacement's script or region fills in only what a locale
#                              leaves out: prs is fa-AF, and prs-IR is fa-IR
# region <code> <REGION>       a UN M.49 number read as a two-letter region: 364 is IR; or a
#                              retired two-letter region read as a current one: SU is RU
# region <language>-<code> <REGION>   a language that picks another of the regions that replaced
#                              a number or a retired region: 810, the Soviet Union, is RU, and
#                              uz-810 is UZ, as uz-SU is
# region <language>-<Script>-<code> <REGION>   the same language in a script that picks otherwise
#                              (und: no language, in that script): uz-Arab-810 is RU
#
# To regenerate after the facts file is, keep these comment lines and put below them the output of
#   grep -E '^(alias|region) ' limn-toolkit/src/test/resources/limn/i18n/cldr-locale-facts.txt
